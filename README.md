# 不動産収益性評価ツール

## 概要
不動産投資物件の収益性を多角的に評価し、投資判断を支援するWebツールです。
12種類の指標を自動計算し、6軸のレーダーチャートで可視化します。

## 機能
- **12指標の自動計算**
  - キャッシュフロー系: 表面利回り、実質利回り、FCR、CCR
  - 投資効率系: ROI、IRR、回収期間
  - リスク系: 実質空室率、返済比率、DSCR
  - 資産価値系: DCF評価額、キャップレート

- **6軸5段階評価 (S/A/B/C/D)**
  - 収益性、実質収益、CF効率、投資効率、安全性、資産価値

- **視覚化**
  - レーダーチャート表示
  - 詳細指標一覧表

## 使用方法

### 1. ファイルを開く
ブラウザで `real_estate_evaluator.html` を開きます。

```bash
# 例: Chromeで開く場合
google-chrome real_estate_evaluator.html

# または、Firefoxで開く場合
firefox real_estate_evaluator.html
```

### 2. 物件情報を入力
以下の情報を入力フォームに記入します：

#### 物件基本情報
- 物件タイプ（一棟マンション/区分マンション/戸建て）
- 物件価格（万円）
- 年間家賃収入（満室想定、万円）

#### 運営経費
- 年間管理費（万円）
- 年間修繕積立金・維持費（万円）
- 年間固定資産税等（万円）
- その他経費（万円）

#### ローン条件
- 借入額（万円）
- 金利（%）
- 借入期間（年）

#### リスク想定
- 想定空室率（%、デフォルト: 5%）
- 年間家賃下落率（%、デフォルト: 0.5%）

#### 自己資金
- 初期投資額（頭金 + 諸費用、万円）

### 3. 評価を実行
「収益性を評価する」ボタンをクリックします。

### 4. 結果を確認
- レーダーチャート: 6軸の評価がビジュアル化されます
- 詳細指標一覧: 全12指標の計算値と評価ランクが表示されます

## 評価基準

### 6軸評価の基準

| 軸名 | S評価 | A評価 | B評価 | C評価 | D評価 |
|-----|------|------|------|------|------|
| 収益性（表面利回り） | ≥10% | 8-10% | 6-8% | 4-6% | <4% |
| 実質収益（実質利回り） | ≥7% | 5.5-7% | 4-5.5% | 2.5-4% | <2.5% |
| CF効率（FCR） | ≥15% | 10-15% | 5-10% | 0-5% | <0% |
| 投資効率（回収期間） | ≤10年 | 10-15年 | 15-20年 | 20-30年 | >30年 |
| 安全性（DSCR） | ≥1.5 | 1.3-1.5 | 1.1-1.3 | 1.0-1.1 | <1.0 |
| 資産価値（評価額/購入価格） | ≥1.2 | 1.1-1.2 | 1.0-1.1 | 0.9-1.0 | <0.9 |

- レスポンシブデザイン対応

## 計算ロジックの詳細

### デフォルト値
- 割引率（DCF計算用）: 5%
- 保有期間: 10年
- 売却時価格: 購入価格の80%
- 税率: 20%（簡易計算）

### IRR計算
ニュートン法を使用した内部収益率の近似計算を実施

### DCF評価額
10年間のキャッシュフロー現在価値と残存価値（売却価格）の合計

## 注意事項
- 本ツールは投資判断の参考情報を提供するものであり、実際の投資は自己責任で行ってください
- 税金計算は簡易的なものです。詳細は税理士にご相談ください
- 市場環境や物件の個別事情により、実際の収益性は異なる場合があります
